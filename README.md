# Data Driven Testing (DDT) in Katalon Studio
This is a katalon studio project to demostrate how to perform Data Driven Testing using data from an external source (i.e., excel file).

We'll be testing "https://demowebshop.tricentis.com/" website for the testing purpose.

A demo video explaining the project structure and funtionalities can be found the video present here:
https://drive.google.com/file/d/1PBVF0ffYnwJQuZOXqRtcuUrxFRZ25ff3/view?usp=sharing 

## Features Tested
- Basic e-commerce flow:
  - login
  - search for products (get the product data from excel file)
  - add to cart
  - perform checkout
  - confirm order
- Order PDF download verification
- more coming soon...

## How to run this project
- Download and Install Katalon Studio from here: https://katalon.com/download
- Download the Test_DemoWebShop project folder
- Open Katalon Studio
- Click on File>Open Project and select the downloaded folder
- Go to the Test Suites>TestSuite_DemoWebShop file
- Run the file
